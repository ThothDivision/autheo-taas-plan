# Roadmap

| Phase | Window | Build | Gate |
| --- | --- | --- | --- |
| **0 · Design** | now – Q1 | Market-structure spec, policy-hook interface shared with TaaS, settlement contract design, intent format | Spec reviewed with counsel and a venue partner |
| **1 · Open tier MVP** | Q1 – Q2 | Concentrated-liquidity pools + order book on Autheo L1 testnet for THEO and stables; THEO fee switch; router v1 | Audit; testnet volume and depth targets |
| **2 · Institutional tier pilot** | Q2 – Q4 | Permissioned order book + RFQ; compliance gate calling TaaS policy; DvP against tokenized deposits; credential presentation | One licensed venue partner, one issuer, 1–2 RWAs (MMF or private credit) |
| **3 · Auctions & agents** | Y2 H1 | Periodic batch auctions, sealed orders (hybrid ML-KEM), agent trading under DID mandates, market-maker programme | Fair-ordering metrics; agent mandates audited |
| **4 · Multi-chain liquidity** | Y2 H2 | Intent router across L0 Mesh destinations, solver bonds in THEO, rule enforcement on destination chains | Cross-chain caps, incident drills |
| **5 · Scale** | Y3 | More jurisdictions and asset classes, white-label venues for banks on TaaS, PQ `max` profile for regulated tenants | Partner venues live in ≥ 2 jurisdictions |
